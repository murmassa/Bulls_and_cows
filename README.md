# Bulls and Cows

Консольная мини-игра **«Быки и коровы»**, написанная на C++.

## About the game

**Bulls and Cows** — логическая игра, в которой один игрок загадывает 4-значное число с уникальными цифрами, а другой пытается его угадать.

После каждой попытки игрок получает подсказку:

- **Bull** — правильная цифра находится на правильной позиции.
- **Cow** — правильная цифра есть в числе, но находится на другой позиции.

## Game Modes

### 1. Computer Guesses

Игрок загадывает число, а **компьютер пытается его угадать**.

Компьютер анализирует полученные результаты и постепенно исключает невозможные комбинации.

### 2. Player Guesses

Компьютер загадывает число, а **игрок пытается его угадать**.

После каждой попытки компьютер сообщает количество быков и коров.

## Rules

- Используется 4-значное число.
- Все цифры должны быть уникальными.
- Первая цифра не может быть `0`.
- `4 Bulls` означают полное совпадение числа.

### Example

Загаданное число:

```text
5831
```

Попытка игрока:

```text
5237
```

Результат:

```text
2 Bulls
0 Cows
```

Цифры `5` и `3` находятся на правильных позициях.

## Computer Strategy

В режиме **Computer Guesses** компьютер использует список всех возможных комбинаций.

После каждой попытки:

1. Компьютер делает предположение.
2. Игрок сообщает количество быков и коров.
3. Компьютер анализирует полученный результат.
4. Невозможные комбинации удаляются из списка.
5. Компьютер выбирает следующую попытку.
6. Процесс продолжается до тех пор, пока число не будет угадано.

Таким образом, компьютер не просто перебирает случайные числа, а постепенно сокращает количество возможных вариантов.

## How to Run

### 1. Clone the repository

```bash

```

Открой проект в **Visual Studio Code**.


